# Полный голосовой стек с самостоятельным размещением

v3rt3p связывает Яндекс.Станцию с распознаванием речи, OpenAI-совместимой языковой моделью и синтезом речи.

Это большой self-hosted-стек, а не домашнее приложение, которое устанавливается одним кликом. Он подойдёт, если вы хотите самостоятельно запускать сервисы, выбирать языковую модель, держать обработку аудио под своим контролем или разрабатывать отдельные компоненты.

## Для кого этот проект

- для операторов, знакомых с Docker, DNS, логами и ключами доступа;
- для тех, кому нужен приватный и настраиваемый голосовой интерфейс;
- для разработчиков протоколов станций, ASR, TTS и LLM-интеграций.

Вам понадобится компьютер, способный запускать несколько контейнеров, место для моделей, каталог базы данных и доступ к OpenAI-совместимой LLM. Для базовой конфигурации достаточно CPU ASR. У ASR-сервиса есть CUDA-образ; требования описаны в [руководстве по быстрому старту](getting-started.md).

## С чего начать

1. Прочитайте [руководство по быстрому старту](getting-started.md).
2. Изучите [архитектуру](architecture.md), чтобы лучше понять внутреннее устройство системы.
3. Откройте раздел [Сервисы](services.md), чтобы найти руководство по настройке и документацию всех протоколов.
